# Maison Atelier

A luxury boutique styling game: run an elegant atelier, dress demanding clients for high-stakes moments, and build relationships and reputation in a glamorous fashion city.

Inspired by the styling loop of boutique-management games and the calendar and confidant systems of social RPGs, with an explorable city on top. All characters, art, names and text are original.

**Status:** early prototype, built in Godot 4.7 with GDScript. Art is placeholder shapes for now.

## Running it

1. Install [Godot 4.7](https://godotengine.org/download) (the standard version, not .NET).
2. Open Godot, click **Import**, and select this folder's `project.godot`.
3. Press **F5** to play.
